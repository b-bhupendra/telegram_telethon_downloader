# ⚡ Telegram Telethon MTProto Downloader Project

A standalone, server-direct MTProto downloader project for Telegram media and files.

---

## 📁 Project Structure

```
telegram_telethon_downloader/
├── config.py         # API_ID, API_HASH, target channel ID, D: drive paths
├── downloader.py     # Core Telethon MTProto download engine
├── main.py           # CLI Entry point
└── README.md         # Usage guide
```

---

## 🚀 How to Run

Run this command in PowerShell or Command Prompt:

```powershell
python C:\Users\homelap\.gemini\antigravity-ide\scratch\telegram_telethon_downloader\main.py
```

1. Enter your Telegram phone number (e.g. `+91XXXXXXXXXX`).
2. Enter the OTP code sent to your Telegram app.
3. The script streams all group files directly to `D:\Telegram_Downloads\Codebasic_Bootcamp\<Section_Heading>\`!
